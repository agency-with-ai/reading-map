# Optional build. Repeat a literature search

Build a small command that repeats a manual search for a spec question. Before building, agree with staff on the search service, inputs, outputs, request limit, and cost limit. Use a supported interface, keep secrets out of shared files, and stop on access errors or limits.

Run it on demand and save candidate titles, URLs, and the query. Compare them with your manual search and check the sources before adding any to the wiki. Leave sources, accepted wiki pages, and the spec unchanged. Manual search is enough for the required work. This helper is optional tooling; the ML build comes in Labs 5 and 6.
